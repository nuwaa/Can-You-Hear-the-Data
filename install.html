CAN YOU HEAR THE DATA? / ATOM S3R

ブラウザーで受信機をインストール

Install the receiver firmware from your browser.

← Webアプリ / Web app

準備 / Before you start

  1. ATOM S3R に ATOMIC ECHO BASE を装着します。
    Attach an ATOMIC ECHO BASE to your ATOM S3R.
  2. Windows、macOS、Linux の Chrome または Edge でこのページを開き、USBデータケーブルで ATOM S3R を接続します。シリアルモニターは閉じてください。
    Use Chrome or Edge on a desktop computer, connect the board with a USB data cable, and close any serial monitor.
  3. 下の確認欄をチェックして「INSTALL」を押し、接続した端末を選びます。書き込みの確認画面でも内容を確認してください。
    Check both boxes, press INSTALL, select your board, and review the flash confirmation.

この操作で選択した端末の既存ファームウェアと保存設定が上書きされます。対象は ATOM S3R 専用です。
This replaces firmware and saved settings on the selected device. This build is for ATOM S3R only.

書き込み後 / After installation

USBを接続し直すか再起動すると、自動でWebアプリの ggwave Audible Normal の受信待機に入ります。Webアプリから短い文章を送信して、ATOM S3R の画面を確認してください。
Reconnect or restart the board. It will listen automatically for ggwave Audible Normal messages from the web app. Send a short message and check the screen.
